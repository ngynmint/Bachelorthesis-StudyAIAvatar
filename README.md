# StudyAIAvatar

My bachelor thesis project :)

This project investigates learning with AI avatars in virtual reality. It examines whether the pedagogical role effects found in text-based conversational agents can be reproduced when learners interact with embodied AI avatars in VR.

The study compares results by the paper *"Who You Explain To Matters: Learning by Explaining to Conversational Agents with Different Pedagogical Roles"* by Xu et al. (DOI: 10.1145/3772318.3790298) to a similar setup in Virtual Reality with an AI avatar.
